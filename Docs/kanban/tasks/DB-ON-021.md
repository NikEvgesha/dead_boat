## Контекст

Победа фиксируется один раз на run ID; каждый игрок получает результат и выходит независимо.

## Правило владельца 2026-10-12

Постоянное сохранение хода сетевого забега не требуется. Награды за сетевой результат должны сохраняться в аккаунте. Отделить выдачу наград от сохранения дистанции/мира/инвентаря онлайн-забега; не включать сетевые checkpoints как условие этой задачи. Перечень текущих наград и точка начисления проверяются по актуальному GameManager/провайдерам. При переходе в соло не допустить повторной выдачи награды исходного run ID этому же игроку.

Следующий шаг — ИИ: после DB-ON-026 реализовать постоянную однократную выдачу наград и восстановление результата выдачи. Владелец: принять выигрыш/награду и независимый выход. Проверка доверия к результату остаётся необходимой частью реализации, готовность серверной проверки не предполагается.

## Готово, когда

- Экран победы показан всем участникам.
- Выход одного не закрывает сцену другим.
- Награда не начисляется дважды по `run ID + player ID`.

## Подсказки ИИ

Постоянную ценную награду не доверять одному браузеру master; зафиксировать решение о серверной проверке.

Следующий шаг — ИИ: протокол постоянного результата и наград; владелец: индивидуальный выход после победы.

## Клиентский пилот наград 2026-10-12

Добавлены отдельное постоянное начисление кристаллов/побед и единый кошелёк с отметками `run ID + player ID`. Соло-ветка сохраняет исходный ключ. Миграция берёт старые Gems/Wins; текущие изменения валюты и побед обновляют новый объект через штатный Mirra SDK. SDK не менялся. Достижения/разблокировки этим протоколом пока не охвачены.

Проверено в Unity: SharedRewardProbe PASS (JsonUtility round trip, повтор после перезапуска/соло, поздний баланс, разные игроки/забеги, нулевая награда, ошибки входа/переполнение/версия). Игровой интеграционный прогон не выполнен: вызовы главного потока Unity не отвечают. В WebGL правки ещё не собраны/не загружены. Статус in_progress сохранён.

Решение о доверии: клиентская идемпотентность — пилот, не защищённая серверная выдача. IDataContainer.Save не даёт C# подтверждение; слияние разных вкладок/устройств и проверка победы master не обеспечены. Cloud Code не используем по ответу Mirra. Серверный claim/атомарный кошелёк остаются открытой частью задачи для публичного релиза.

Подробности и приёмка: Docs/COOP_REWARDS_20261012.md. Следующий шаг — ИИ: Editor интеграция и новая тестовая сборка; владелец: сейчас тестировать предыдущую сборку возврата, затем принять награды. Внешняя команда/ИИ: выбрать доверенный backend и проверить гарантии сохранения.

Клиентская выдача ограничена Editor/DEADBOAT_MIRRA_DIAGNOSTICS. Публичная сборка возвращает RequiresServer до реализации доверенного claim; карточка не закрывается как готовая для релиза.
