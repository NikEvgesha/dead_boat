## Контекст

Победа фиксируется один раз на run ID; каждый игрок получает результат и выходит независимо.

## Правило владельца 2026-10-12

Постоянное сохранение хода сетевого забега не требуется. Награды за сетевой результат должны сохраняться в аккаунте. Отделить выдачу наград от сохранения дистанции/мира/инвентаря онлайн-забега; не включать сетевые checkpoints как условие этой задачи. Перечень текущих наград и точка начисления проверяются по актуальному GameManager/провайдерам. При переходе в соло не допустить повторной выдачи награды исходного run ID этому же игроку.

Следующий шаг — ИИ: после DB-ON-026 реализовать постоянную однократную выдачу наград и восстановление результата выдачи. Владелец: принять выигрыш/награду и независимый выход. Проверка доверия к результату остаётся необходимой частью реализации, готовность серверной проверки не предполагается.

## Готово, когда

- Экран победы показан всем участникам.
- Выход одного не закрывает сцену другим.
- Награда не начисляется дважды по `run ID + player ID`.

## Подсказки ИИ

Постоянную ценную награду не доверять одному браузеру master; зафиксировать решение о серверной проверке.

## Реализация 2026-10-05

RunWon передаёт результат всем; повтор Win не выдаёт вторую локальную награду. Реальный Forest-босс и второй transport peer подтвердили победу в Editor. Постоянные награды/победы/разблокировки изолированы SharedRunPreviewSave; серверная проверка и долговечная выдача не реализованы. Следующий шаг — ИИ: протокол постоянного результата и наград; владелец: индивидуальный выход после победы.
