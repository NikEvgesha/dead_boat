## Контекст

Event уже четвёртая запись Levels.asset, LevelEvent включён в Build Settings, Managers использует этот каталог. Сейчас картинка лесная, допуск определяется только Unlocked. Поручение владельца: добавить полноценный вход на экран выбора, сохранив остальную игру.

## Готово, когда

- Сохранены стабильные IDs обычных карт 0–2 и Event3. Фильтрация/группировка UI не превращает порядковый индекс видимой строки в другой LevelID и не ломает старое сохранение/recovery.
- Эвентовая карточка имеет своё изображение и локализованные RU/EN название/описание/сроки/состояния, работает на мыши и сенсоре. Существующий ключ Level/Event переиспользован.
- Показ/доступность берутся из кодового календаря 262; фактический solo/departure start повторно проверяет допуск, в том числе после ожидания/отсчёта и по старому приглашению.
- Способ представления solo/кооп соответствует 263: текущая локальная реализация саней не выдаётся за готовую сетевую. Перед публичным кооп-стартом нужен сетевой босс, либо явно согласованное владельцем ограничение режима.
- Закрытое окно запрещает новые старты; принятый забег и допустимый возврат в живую сессию сохраняются. Результаты UI/режимов/реального черновика приняты отдельно.
