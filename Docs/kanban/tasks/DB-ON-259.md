## Контекст

Статическая проверка пакета передачи DB-ON-258 нашла две отсутствующие GUID: 070a68964028def489b88b991aedbdbb (m_NavMeshData в overrides домов/Clocks и вариантов мастерских) и 870d564c8687e0940ae7b991de0a9125 (m_Sprite в Lizzi). Обе ссылки уже присутствуют в базовом b603157f; Unity AssetDatabase.GUIDToAssetPath для них возвращает пустую строку. В изменяемых файлах найдено 11 таких ссылок; общий старый проект может содержать больше.

## Готово, когда

- Проверены реальные активные компоненты и назначение отсутствующего UI-спрайта после чистого импорта.
- Для NavMesh выяснено, не являются ли ссылки неиспользуемыми старыми overrides; нужная активная навигация восстановлена с проверкой проходов/врагов.
- Отсутствующий спрайт восстановлен из подтверждённого источника либо поле исправлено по назначению UI; случайный заменитель не назначается.
- Сохранены поздние визуальные правки, исходные GUID префабов и контекст карточек. Исправленные игровые сценарии проверены, ручная приёмка отмечена отдельно.

## Подсказки ИИ

Не пересобирать дома целиком и не вырезать неизвестные overrides вслепую. До изменений сравнить с b603157f и найти все вхождения через rg. Проверить actual NavMeshSurface.navMeshData в экземплярах, а не только YAML. Это найденный при передаче старый технический долг; сводка DB-ON-258 его не исправляла. Новый editor-кэш без ошибок компиляции не доказывает отсутствие этой проблемы.
