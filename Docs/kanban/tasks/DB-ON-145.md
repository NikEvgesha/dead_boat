## Контекст

В новой локации у торговцев уже есть визуальные места. Переносим прежний функционал действующего лобби к этим местам, сохраняя новый внешний вид. Не считать выставочную вывеску работающим магазином.

## Готово, когда

- Составлен полный реестр действующих магазинов/сервисов старого Lobby: функция, старые ссылки, новая точка, способ открытия/выхода и результат проверки.
- Каждый реально существующий сервис привязан к соответствующему месту новой сцены: продажи/покупки/профессии/банк/рейтинг и прочие найденные функции не потеряны; несуществующие услуги не выдаются за перенесённые.
- Каталоги, цены, сохранение владения, награды, локализация и интеграции SDK используют действующие системы без дублей менеджеров и второй экономики.
- Рядом с новым визуалом нет старых зданий/витрин/перекрывающих триггеров; взаимодействие E/касание и выход корректно возвращают управление.
- Выполнена матрица новой сцены online/offline/возврат из забега/перезапуск/реклама; недоступные без сети услуги показывают понятное состояние, локальные остаются доступны.

## Подсказки ИИ

Начать с инвентаризации Lobby, LobbyIslandWorkshop и Docs/assets/lobby-island/README.md; названия магазина не заменяют проверку его живого обработчика.
