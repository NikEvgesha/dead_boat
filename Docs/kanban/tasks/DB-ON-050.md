## Контекст

Mirra Cloud SDK v0.10.0 успешно выполняет гостевой вход в локальном WebGL, но из iframe тестового черновика Яндекс Игр сообщает `HTTP 500 Unknown Error`. В действующем CSP нет `sdk.mirracloud.com`. Консоль Яндекса перед отправкой запроса на новый хост требует черновик полноценной игры, а текущая изолированная тестовая сцена не подходит. CSP пока не доказан единственной причиной ошибки.

2026-09-29 после анонса исправления CORS на стороне Mirra Cloud тот же текущий черновик повторно показал `HTTP 500 Unknown Error`. SDK в проекте уже `v0.10.0`; сборка и CSP после прошлого теста не менялись. Требуется проверка по критериям ниже.

2026-09-29: добавлен отдельный способ собрать все игровые сцены с диагностической панелью Mirra и проверкой пустого API-токена. Сборка и повторная проверка в Яндекс Играх продолжаются; критерии ниже ещё не приняты.

2026-09-29: Unity `6000.3.9f1` в batchmode успешно собрала пять игровых сцен; результат `Builds/MirraCloudPlayableDraft`, ZIP для тестового черновика `Builds/DeadBoatMirraPlayableDraft-20260929.zip` (33,64 МБ). В `index.html` есть локальные зависимости WebView, в ZIP — `index.html`, игровые данные и загрузчик. Самый большой распакованный файл WebGL — WASM 76,56 МиБ. Поле `Configuration.Token` проверено пустым перед сборкой; сам сборщик также запрещает непустое значение. В браузере и на Яндекс Играх эту сборку ещё не проверяли: инструмент управления браузером не запустился, владелец пока не может загрузить архив вручную. Не считать первый критерий принятым до запуска игрового черновика.

2026-09-30: владелец сообщил о загрузке новой сборки. Повторное открытие консоли черновика `424778` пока показывает прежний архив 19,19 МБ от 29.09.2026 20:34:40; открытие ссылки черновика запускает отдельную тестовую сцену с `HTTP 500 Unknown Error`. Полноценный архив 33,64 МБ в сохранённом черновике ещё не подтверждён. В настройках CSP доступно редактирование запроса; текущий разрешённый список не содержит `sdk.mirracloud.com`. Уточняем, куда был загружен новый архив и сохранён ли черновик, прежде чем отправлять запрос CSP.

2026-09-30: после повторной загрузки владельцем консоль `424778` показывает новый архив 32,08 Mb (размер, показанный Яндексом), изменение 13:04:08 30.09.2026, новый `file-id=13610570`. Черновик открыл полноценное игровое лобби с мечом и диагностической панелью; панель всё ещё показывает `HTTP 500 Unknown Error`. Запрос CSP отправлен только для `sdk.mirracloud.com`; консоль подтверждает получение и статус обработки. Хост ещё не одобрен и не добавлен в действующий список. Консоль также показывает замечание о распакованном файле больше 100 МБ; причина замечания для нового архива пока не установлена. Следующий тест входа — после решения по CSP.

## Готово, когда

- В черновике восстановлена запускаемая игровая сцена с диагностикой входа Mirra Cloud и безопасной конфигурацией без Editor API-токена.
- Запрошен только необходимый хост `sdk.mirracloud.com` с описанием назначения; запрос одобрен и хост появился в действующем списке CSP.
- В iframe Яндекс Игр подтверждён гостевой вход на двух независимых сессиях браузера или записана новая точная ошибка с HTTP/консольными данными без токенов и данных игроков.
- Проверено, что при отказе Mirra Cloud игра остаётся доступна офлайн.

## Подсказки ИИ

См. `Docs/MIRRA_CLOUD_FIELD_NOTES.md` (MC-11—MC-13), DB-ON-009 и тестовую сцену `Assets/Online/SmokeTest`. Не отправлять на модерацию и не публиковать игру ради этой проверки. В CSP-форме Яндекса уже разрешённые `exitgames.com` и `photonengine.io` не надо повторно добавлять в поле запрашиваемых хостов. Перед проверкой оставьте токен в `Configuration.asset` пустым и не показывайте секреты в логах. По сообщению владельца, ранее использованный токен удалён 2026-09-29.
