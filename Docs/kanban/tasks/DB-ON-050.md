## Контекст

Mirra Cloud SDK v0.10.0 успешно выполняет гостевой вход в локальном WebGL, но из iframe тестового черновика Яндекс Игр сообщает `HTTP 500 Unknown Error`. В действующем CSP нет `sdk.mirracloud.com`. Консоль Яндекса перед отправкой запроса на новый хост требует черновик полноценной игры, а текущая изолированная тестовая сцена не подходит. CSP пока не доказан единственной причиной ошибки.

## Готово, когда

- В черновике восстановлена запускаемая игровая сцена с диагностикой входа Mirra Cloud и безопасной конфигурацией без Editor API-токена.
- Запрошен только необходимый хост `sdk.mirracloud.com` с описанием назначения; запрос одобрен и хост появился в действующем списке CSP.
- В iframe Яндекс Игр подтверждён гостевой вход на двух независимых сессиях браузера или записана новая точная ошибка с HTTP/консольными данными без токенов и данных игроков.
- Проверено, что при отказе Mirra Cloud игра остаётся доступна офлайн.

## Подсказки ИИ

См. `Docs/MIRRA_CLOUD_FIELD_NOTES.md` (MC-11—MC-13), DB-ON-009 и тестовую сцену `Assets/Online/SmokeTest`. Не отправлять на модерацию и не публиковать игру ради этой проверки. В CSP-форме Яндекса уже разрешённые `exitgames.com` и `photonengine.io` не надо повторно добавлять в поле запрашиваемых хостов. Перед проверкой оставьте токен в `Configuration.asset` пустым и не показывайте секреты в логах. По сообщению владельца, ранее использованный токен удалён 2026-09-29.
