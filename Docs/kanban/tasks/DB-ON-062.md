## Контекст

Владелец просит сохранить существующие деревянный/каменный дома и сделать рядом ещё варианты: выше или шире, с уникальным наполнением.

## Готово, когда

- Два исходных дома сохранены; рядом добавлены два деревянных и два каменных варианта.
- Варианты отличаются пропорциями, оформлением и содержимым, каждый имеет отдельный префаб.
- Проверены проходы, закрытая крыша и материалы, сохранена сцена.
- Владелец оценил коллекцию.

## Подсказки ИИ

Не перезаписывать существующие варианты и несвязанные правки. Для каменных вариантов сохранить отсутствие коричневого. Высокие варианты — просторные одноэтажные залы с потолком 4.0; широкие — расширенные помещения для ремесла/хранения. Не обещать второй этаж без лестницы/проверки.
