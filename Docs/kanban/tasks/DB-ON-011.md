## Контекст

Друг входит в текущую комнату при наличии места; иначе группа вместе переходит в подходящую или новую комнату.

## Разбор реализации 2026-10-08

Прочитаны LobbyOnlineBootstrap.ConnectAsync/StopRunnerAsync, LobbySessionBrowser и установленный штатный Mirra SDK 0.10.0. GroupsService предоставляет CreateInviteAsync/AcceptInviteAsync/DeclineInviteAsync с groupId+inviteId и приглашение по ключу. В публичной поверхности установленного SDK не найден метод списка входящих групповых приглашений или событие их доставки. GetMyGroupsAsync возвращает уже существующие членства, а не входящие приглашения. Наличие сервера inbox НЕ опровергнуто; доступ через SDK пока не подтверждён. Cloud Code не используем по ответу команды Mirra. Прямые обходные REST вызовы и правки SDK не добавлены.

Игровой переход пока не реализован. Перед ним нужны доставка адресного приглашения, подтверждение получателем и общий party rendezvous. Приглашение должно содержать регион/версию/целевую комнату/срок, проверяться повторно при принятии; истёкшее или чужое приглашение не отключает текущую комнату. Для полного лобби сначала согласуется новая комната для всей приглашённой группы; два независимых random join недопустимы. Открывать новую комнату другим игрокам только после подтверждения участников, с таймаутом и отказом/возвратом при ошибках. Проверка PlayerCount из каталога сама по себе не резервирует места. Mirra группа не является Photon комнатой и её создание не обеспечивает резерв CCU.

Следующий шаг — ИИ: подтвердить доступный путь доставки через штатный SDK либо реализовать переносимый код приглашения как явно отдельный пользовательский сценарий; затем согласование группы и переход. Команда Mirra/владелец: уточнить SDK путь получения входящих group invites, если требуется адресное уведомление. Запрос команде автоматически не отправлен. Владелец принимает сценарии заполненной комнаты и гонки за место после реализации.

## Реализация в рабочей ветке 2026-10-08 — ещё не приёмка

Добавлены `LobbyFriendInvites`, кнопка «Пригласить» в списке друзей и поле ввода кода. Отправитель создаёт приватную Mirra-группу и адресное трёхминутное приглашение выбранному профилю; код `DB1:<groupId>:<inviteId>` копируется в буфер, его нужно передать другу вне игры. Получатель принимает приглашение штатным SDK, после чего читает данные комнаты (версия игры, регион, срок и имя). Это пока **не уведомление в игре**: в SDK 0.10.0 не найден входящий inbox. Ключи доступа в код приглашения не входят.

При наличии места отправитель после принятия сообщает имя текущей Photon-комнаты. При заполнении до или во время ожидания создаёт отдельную скрытую комнату на 10 мест, публикует её имя через Mirra metadata, ждёт сетевой аватар профиля друга и только затем делает комнату видимой общему каталогу. Получатель не создаёт комнату случайно; неудачный переход запускает обычное переподключение. Добавлен 12-секундный таймаут отдельного SDK-запроса и попытка удалить временную Mirra-группу после завершения. ID незавершённой группы сохраняется локально для попытки уборки при следующем приглашении. При аварийном закрытии приложения группа всё же может остаться на сервисе без TTL, хотя сам адресный инвайт истечёт — уборка таких групп не проверена.

Проверено: отдельная компиляция нового Mirra-адаптера с реальными MirraCloudSDK.dll и Unity assemblies прошла без предупреждений. Полную Unity-компиляцию/двухклиентский сценарий пока **не подтверждали**: текущий Unity CLI подключён к другому проекту, а редактор dead_boat не зарегистрирован в Pipeline. ZIP/черновик не менялись. Следующий шаг ИИ: проверить полную компиляцию в Unity, затем тестировать две учётные записи на свободной и заполненной комнате, гонку за последнее место, истечение/чужой код и восстановление после сбоя. Владелец: после технического теста принять пользовательский сценарий или запросить у Mirra inbox для уведомлений.

## Готово, когда

- Приглашение показывает место, регион и версию.
- Полное лобби переводит всю группу без потери party.
- Новая комната позже допускает других игроков.

## Подсказки ИИ

Не отправлять друга одного в новую комнату; учитывать гонку за последние свободные места.
