## Контекст

Владелец выбрал вариант 07: вытянутый оазис с сухим обходом и пологим входом на мелководье. Для ручной проверки нужна отдельная рабочая сцена.

## Готово, когда

- В Unity открывается прогулка по варианту 07.
- Персонаж обходит пруд по суше, спускается на мелководье и возвращается на берег.
- Пять пробных предметов доступны для подбора, декор опирается на грунт.

## Подсказки ИИ

Сохранять сухой обход и проверять контакт стволов с песком по видимой геометрии. Игровую замену выполнять отдельной задачей после приёмки.

## Результат

Размер водной поверхности — 43 × 29 м по крайним точкам, площадь 868 м². У ближнего берега перепад до воды 0,42 м на 3,4 м. Видимые основания трёх пальм заглублены на 1,4–2 см относительно реальной поверхности песка, основания камышей — примерно на 0,9 см.

В рабочем окне капсула игрока прошла сухой круг, спустилась на мелководье и вернулась к старту. Подбор сработал для 5 из 5 пробных предметов. Окно открыто у ближнего берега, предметы сброшены. Игровые префабы Pond оставлены без изменений этой задачей.

## Следующий шаг

Владелец одобрил перенос пруда на оба берега. Подключение к игровым префабам и проверка выполняются в DB-ON-228.
