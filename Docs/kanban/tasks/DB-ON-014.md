## Контекст

В лобби игрок подходит к точке посадки и выбирает существующий экипаж либо создание нового.

2026-09-30: существующая `GameStartPoint` уже открывает выбор карты (`LevelMapUI`), но этот UI сразу запускает одиночный уровень. Выбор карты для одиночного пути теперь предварительно отключает Photon. Для списка отправлений из разных игровых лобби потребуется отдельный источник списка: текущий `NetworkRunner` находится внутри игровой Session, а официальный Fusion `OnSessionListUpdated` приходит при входе в matchmaking Lobby. До выбора способа получения списка не добавлять клиенту второе постоянное Photon-подключение, которое может увеличить расход CCU.

2026-09-30: добавлен экран `LobbyDepartureUI` перед выбором уровня: список открытых ожидающих экипажей с уровнем и числом игроков, создание своего, отдельная кнопка solo, выход обратно в общий лобби. При открытии один Runner покидает визуальное лобби и входит в отдельный Photon matchmaking lobby `river-departures-v1`; второго постоянного подключения нет. Компиляция Unity прошла без ошибок. Нужна ручная проверка на двух клиентах WebGL: появление отправления, вход из другого общего лобби, выход без старта забега и возврат в общее лобби. Запуск забега относится к DB-ON-016/017.

## Готово, когда

- UI показывает доступные отправления, уровень и состав.
- Открытие UI не требует стоять на точке постоянно.
- Выход из UI не отправляет игрока в забег.

## Подсказки ИИ

Начать с `LobbyManager.StartGame()`; разделить одиночный запуск и сетевую посадку.
