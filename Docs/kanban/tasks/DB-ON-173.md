## Контекст

Владелец просит найти ранее переделанный замок с новыми домами и добавить его как основу дальнейшего оформления ивентовой карты. Найдена версия CastleServices_01 из CastleServicesWorkshop с последними сохранёнными правками DB-ON-087.

## Готово, когда

- Подготовлен отдельный префаб замка с шестью переделанными домами.
- Проверены импорт, игровые ветки домов и зависимости.
- Владелец может осмотреть результат перед оформлением под ивент.

## Подсказки ИИ

Убрать из копии две выставочные лодки и EditorOnly-модели товаров. Замена замка в LevelEvent следует после адаптации его размеров, точек и оформления.

## Результат

Версия с обновлёнными домами найдена в Assets/Scenes/CastleServicesWorkshop.unity и сохранённом CastleServices_01.prefab. Подготовлена отдельная копия Assets/Events/CastleBase/EventCastle_Base.prefab с новым GUID. Из копии исключены две лодки сравнения и три демонстрационные группы товаров. В шести домах сохранены девять StorePoint и два SellPoint. Unity 6000.3.9f1 импортировал и сохранил префаб без отсутствующих скриптов. Проверено разрешение локальных ссылок сериализованного файла. Осмотрен снимок Docs/locations/previews/event-castle-base173.png.

Префаб подготовлен как база оформления. LevelEvent пока использует NY_Castle. Для подключения нужно совместить новый замок с игровым берегом, проверить точки взаимодействия и повторное появление, затем перенести зимний декор на геометрию новых домов. Play Mode не запускался.

Следующий шаг: владелец сверяет найденную версию по снимку. ИИ адаптирует этот замок под ивентовый маршрут и проверяет подключение.
