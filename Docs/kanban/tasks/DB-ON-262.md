## Контекст

Владелец 13.11.2026: эвенты настраиваются кодом, даты запуска и окончания он предоставит. Сейчас календаря в допуске нет. Не подключать Mirra Remote Config, Cloud Code или ручное изменение часовых поясов устройства вместо этой конфигурации. Реальные даты пока не заданы.

## Готово, когда

- Есть единый кодовый реестр eventId, content/theme revision и start/end в DateTimeOffset UTC. Не назначены вымышленные праздничные даты; без корректного окна публичный новый запуск закрыт, есть Editor-only preview.
- Чистые тесты проверяют [start,end), точные границы, отсутствие/ошибку дат, start>=end, культуры/таймзоны и повторные вызовы; время подаётся через проверяемый clock provider. Источник доверенного времени/ограничения клиентских часов описаны честно.
- Один API используют выбор карты, solo, создание/присоединение к экипажу, countdown и фактический переход. Старый invite/открытый UI не обходят новый допуск.
- Предлагаемое правило приёмки: принятое до end прохождение разрешено закончить после end. Новые старты закрываются; живой return ticket и разрешённый ContinueSolo используют принятую версию контента. Если владелец выбирает другое правило, учесть при приёмке перед публичным включением, не останавливая подготовку ревью-результата.
- Event/theme revision фиксируются вместе с seed, LevelID, RunRandom/pool revision в сессии/возврате/solo-ветке. Тема не выбирается заново по сегодняшней дате; версии протокола и совместимости обновлены согласованно.
- Проверены окончание окна во время countdown, refresh, смена ведущего, потеря сети, продолжение одному и отсутствие живого экипажа. Смена темы не меняет уже принятый мир/награды.
