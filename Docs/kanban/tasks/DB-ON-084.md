## Контекст

Уменьшить коврики винтовки/дробовика до размеров остальных. Убрать фиксированные названия оружейной, сохранить случайный ассортимент. Добавить оружие/щиты на стены. Все надписи текущей локации перевести в UI с локализацией; имена товаров должны приходить из фактического товара StorePoint.

## Готово, когда

- Исходная сцена сохранена, checkpoint DB-ON-084 создан.
- Коврики одинакового размера, статичные подписи оружейной убраны, случайный выбор восстановлен.
- Есть настенный декор; надписи локации используют UI и ключи локализации, товарные имена заполняются существующим StorePoint.
- Сериализация, текстовые ссылки, визуальное размещение проверены; сцена/префабы сохранены.
- Владелец оценил результат и проверил в игре после восстановления Fusion.

## Подсказки ИИ

Сохранять текущие правки владельца. Fusion отсутствует: игровые компоненты временно Missing Script; не распаковывать источники. Для локализации использовать существующие LocalizedText/LocalizationData, для случайного имени товара — StorePoint._name. Английский preview проверяет геометрию текста, а не поведение менеджера языка.

## Ожидает проверки

Визуальная приёмка владельца. Полная игровая компиляция и проверка покупки, подбора другим игроком, смены языка и имени случайного товара в Play Mode не выполнены из-за отсутствующего Fusion. Привязки Missing Script сохраняют настоящие GUID, игровые источники не распакованы.

Следующий шаг — владелец проекта: оценить оружейную и новые UI-вывески в Unity. После восстановления Fusion ИИ проверяет инициализацию случайного ассортимента, переключение языка и выдачу, владелец проводит ручную игровую приёмку.
