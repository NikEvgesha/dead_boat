## Контекст

Проверка сообщений обязательна до доставки другим игрокам, одной клиентской фильтрации недостаточно.

## Готово, когда

- Запрещённое сообщение не доставляется.
- Есть rate limit, mute/жалоба и обработка обходов фильтра.
- Правила не раскрывают личные данные в логах.

## Подсказки ИИ

Проверить серверную модерацию провайдера и язык аудитории; не считать простой список слов полной защитой.
