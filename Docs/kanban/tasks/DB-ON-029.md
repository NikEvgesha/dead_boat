## Контекст

Прототип подключает лобби Fusion Shared и сохраняет одиночный путь при ошибке подключения.

## Готово, когда

- Реализация есть в рабочей ветке.
- Локальное подключение и базовый fallback проверены.

## Подсказки ИИ

При изменениях повторно проверить регрессию solo и не трактовать прототип как готовый reconnect.
