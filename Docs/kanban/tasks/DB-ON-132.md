## Контекст

Владелец сообщил, что другие разработчики вынуждены вручную импортировать Photon. Причина подтверждена: .gitignore исключал Assets/Photon и Assets/Photon.meta. Установка SDK не передавалась через Git.

## Готово, когда

- Установленный Photon Fusion2.1.3 Stable2390 и его metadata/config хранятся в Git.
- Состав и SHA256 файлов SDK совпадают с установленной рабочей копией, нет отсутствующих библиотек/платформенных файлов.
- Инструкция запуска не требует скачивания и импорта SDK.
- Другой разработчик подтвердил запуск Unity после pull/клонирования без ручного импорта Photon.

## Подсказки ИИ

06.11: убрано исключение всей папки Photon; добавляются SDK, исходные GUID, DLL/WebGL/native файлы, конфигурация Fusion и клиентский App ID. Исходники SDK не изменяются. Mirra Cloud, MCP/UPM-обновление и несвязанные настройки проекта не включаются. Сборка не требуется.

ИИ проверяет полноту через Git export и хеши. Ручной запуск на другом компьютере пока не подтверждён, поэтому in_review.

## Следующий шаг
