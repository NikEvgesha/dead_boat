## Контекст

Владелец попросил подготовить пять вариантов улучшения Ship 1 в стилистике игры. Выбранный вариант будет перенесён в 3D после просмотра.

## Готово, когда

- Подготовлены пять самостоятельных эскизов в стилистике текущей игры.
- Во всех вариантах узнаётся исходный наклонённый корпус, а подход к палубе читается по картинке.
- Владелец выбрал вариант или сочетание деталей.

## Подсказки ИИ

По кадру из Unity сохранить низкий нос, открытую палубу, сломанные мачты, корму на высокой скале, бирюзовое мелководье и плоские цвета крупных граней. Выбранные изменения маршрута и точек лута проверять при переносе в Unity.

## Результат

Встроенный imagegen использовал контрольный кадр исходного префаба из Unity как ориентир по силуэту, ракурсу и стилю. Пять заданий для 2D-эскизов: вход с трапом, фонарём и красным флагом, открытый трюм с ящиками, береговой привал с небольшим навесом, заросшее мелководье с плоскими камнями, кормовая площадка с лестницей вдоль скалы. Эскизы сохранены отдельно под номерами 01–05.
