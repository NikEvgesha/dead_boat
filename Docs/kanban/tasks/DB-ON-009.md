## Контекст

Для друзей, приватных отправлений и восстановления забега нужен устойчивый ID; клиентский ID нельзя считать доказанной личностью.

## Готово, когда

- ID переживает перезапуск и вход на поддерживаемой площадке.
- Photon получает проверяемую идентичность.
- Секреты отсутствуют в WebGL-билде.

## Подсказки ИИ

Сначала изучить аутентификацию издательских площадок и Mirra Cloud; не класть серверные ключи в Assets.

2026-09-29: в отдельном проекте Mirra Cloud `Dead Boat` создана Web-платформа `yandex-games` с гостевым входом для теста. Unity SDK `v0.10.0` добавлен в UPM; отдельная сцена проверяет гостевой вход без изменения основного маршрута. Локальный WebGL в браузере показал `Guest login OK`; в iframe черновика Яндекс Игр ответ SDK `HTTP 500 Unknown Error`, а `sdk.mirracloud.com` пока отсутствует в разрешённых CSP-хостах. Прямой запрос к Mirra Cloud ответил `200`, поэтому причина ошибки в iframe требует повторной проверки после CSP. Поле `Configuration.Token` не используется гостевым входом SDK и должно быть пустым в WebGL; сборка теперь это проверяет. По сообщению владельца, ранее использованный тестовый токен удалён 2026-09-29; в Hub это отдельно не проверялось. Гостевой вход не выполняет критерий постоянного ID между устройствами и не удостоверяет личность для Photon. Для входа Яндекс Игр интеграция Mirra Cloud требует ID приложения и секрет на стороне Mirra; позже проверить безопасный перенос/связку гостевого профиля и аккаунта площадки.
