## Контекст

Для друзей, приватных отправлений и восстановления забега нужен устойчивый ID; клиентский ID нельзя считать доказанной личностью.

## Готово, когда

- ID переживает перезапуск и вход на поддерживаемой площадке.
- Photon получает проверяемую идентичность.
- Секреты отсутствуют в WebGL-билде.

## Подсказки ИИ

Сначала изучить аутентификацию издательских площадок и Mirra Cloud; не класть серверные ключи в Assets.

2026-09-29: в отдельном проекте Mirra Cloud `Dead Boat` создана Web-платформа `yandex-games` с гостевым входом для теста. Unity SDK `v0.10.0` добавлен в UPM; отдельная сцена проверяет гостевой вход без изменения основного маршрута. Гостевой вход не выполняет критерий постоянного ID между устройствами и не удостоверяет личность для Photon. Для входа Яндекс Игр интеграция Mirra Cloud требует ID приложения и секрет на стороне Mirra; позже проверить безопасный перенос/связку гостевого профиля и аккаунта площадки. Клиентский API-токен и WebGL-проверка ещё не выполнены.
