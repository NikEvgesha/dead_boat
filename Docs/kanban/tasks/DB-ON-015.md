## Контекст

Лидер выбирает уровень, размер экипажа и видимость. Публичное ожидание должно быть доступно из разных лобби региона.

2026-09-30: реализовано создание открытого публичного отправления на 2–4 места с проверкой открытого уровня и листингом через Photon Session Properties. Одно место сейчас означает явный одиночный путь без Photon. Режим «Только друзья» и приглашение по ID ещё не реализованы: скрытая Session без проверенной личности игроков не обеспечивает требуемый допуск. Совместный забег из комнаты ожидания пока не запускается.

## Готово, когда

- Валидируются уровень и 1–4 места.
- Публичные отправления видны подходящим игрокам.
- Для друзей действует приглашение по ID и проверка допуска.

## Подсказки ИИ

Скрытая Session не является достаточной авторизацией friends-only; нужна проверка состава доверенным сервисом либо явно ограниченная приватность.
