## Контекст

Для общих параметров лодки владелец утвердил правило: по каждому параметру отдельно выбирать лучший итоговый бонус профессии одного участника и лучший итоговый бонус животных одного участника. Выбор может указывать на разных игроков для скорости, топлива и расхода. Карты лодки всех участников складываются. Личные эффекты, включая вместимость инвентаря, остаются у владельца.

## Готово, когда

- Authority считает общий набор на старте забега, повторяет расчёт при восстановлении с тем же составом и сообщает итог всем клиентам.
- Для каждого параметра лодки выбирается лучший бонус профессии и лучший совокупный бонус экипированных животных **одного игрока**. Уменьшение расхода топлива сравнивается в правильном направлении (меньший множитель лучше); равные значения дают один и тот же результат независимо от порядка игроков.
- Прибавки карт лодки всех участников суммируются: плоские величины складываются, для множителей складываются отклонения от нейтрального `1` (например, +20% и +10% дают +30%). Вклад каждого игрока применяется один раз.
- Личные бонусы профессий, животных и карт остаются личными; вместимость инвентаря не превращается в общий запас команды.
- Четыре игрока видят одинаковые параметры корабля.

## Подсказки ИИ

Это новое решение заменяет прежнее суммирование корабельных бонусов животных всех игроков в этой карточке и `Docs/WEB_MULTIPLAYER_IMPLEMENTATION_ROADMAP.md`. Внутри набора одного игрока животные пока складываются по `AnimalRunBuffs.Add`. Для процентов сначала определить нейтральное значение и направление пользы для каждого поля `BoardController`; не выбирать целый набор одного игрока по одному показателю. Проверить баланс 4 игроков и нижнюю границу расхода топлива; не вводить неутверждённый предел эффектов. Карта инвентаря — DB-ON-042.

## Реализация 2026-10-05

Shared master хранит один профиль на участника; лучший итог профессии и лучший набор животных выбираются отдельно по параметру, расход — меньший множитель; карты складываются через отклонение от 1. Повтор профиля заменяет вклад. Два Cloud peers подтвердили топливо 2360, скорость 155 и множитель пополнения 2.184 без удвоения. Профили сообщаются клиентами и не подходят для доверенной выдачи постоянных наград. Следующий шаг — владелец: четыре разных набора бонусов в WebGL; ИИ: исправить расхождения.
