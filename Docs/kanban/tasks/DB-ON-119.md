## Контекст

Владелец хочет разобраться в существующих наборах, сохранить список предметов с путями и идеями использования и собирать новые дома и пропсы в отдельной сцене Unity.

## Готово, когда

- Просканированы все папки Assets; каталог отличает префабы, модели и вспомогательные ресурсы.
- Сохранены точные пути, категории и предложения использования; предположения явно отделены от проверенных свойств.
- В Unity открыта отдельная сохранённая сцена для сборки, доступен список предметов.
- Владелец проверил удобство каталога и выбрал первый объект для совместной сборки.

## Подсказки ИИ

Не менять исходные ассеты, игровые сцены и Build Settings. Варианты материалов и модели не считать уникальными предметами. Не запускать gameplay при демонстрации.

## Источники

- Запрос владельца от 2026-10-06.
- `Assets/Import`, `Assets/Prefabs`, `Assets/Models`, остальные папки `Assets`.

## Проверки и следующий шаг

2026-10-06: подготовлены `Docs/assets/README.md`, сводка всех папок `FOLDERS.md`, полные `inventory.csv`/`inventory.json` и генератор `tools/assets/build_catalog.py`. Проверено 5457 уникальных существующих путей: 1754 префаба, 3665 моделей разных форматов, 38 воксельных исходников. Это файлы, а не число уникальных предметов. Все пути примеров справочника проверены; идеи использования основаны на именах. Просмотрены превью pillarWood, planks, wallWood, roofGable.

Unity 6000.3.9f1 открыт после активации лицензии владельцем. Через локальный MCP (`127.0.0.1:28086`) создана, открыта и сохранена `Assets/Scenes/AssetWorkshop.unity`: камера, свет, пустая область сборки, 16 образцов Kenney Fantasy Town с подписями. Build Settings и существующие сцены не менялись. Окно каталога показывает 5457 записей, основной фильтр — 3008. Проверены поиск pillarWood, размещение через метод кнопки, сохранение связи с исходным ассетом, отмена одним Undo; после отмены область сборки пуста, сцена сохранена. Проверен рендер Scene View через MCP.

Ограничение: текущий игровой код не компилируется из-за отсутствующих типов Photon Fusion (Networked, Rpc, RpcTargets, INetworkStruct и другие). Это обнаружено при первом запуске; SDK и онлайн-код не менялись. Инструмент вынесен в отдельную Editor-сборку, DLL построена; из-за общей ошибки компиляции новая сборка ещё не загрузилась штатным reload. В текущем сеансе окно запущено через MCP script-execute, проверенный C# источник сохранён. До устранения ошибок игры пункт меню может быть недоступен; ИИ может повторно открыть окно через MCP.

Следующий шаг: владелец — проверить каталог/мастерскую и выбрать первый дом или пропс. ИИ — собрать выбранный объект вместе с владельцем и дополнять каталог проверенными свойствами; проблему локальной установки Fusion рассмотреть отдельно. Статус in_review до приёмки владельца.
