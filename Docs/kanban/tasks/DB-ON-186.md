## Контекст

Владелец хочет самостоятельно подняться по лестнице исходного домика с доработками, пройти по площадкам и попробовать сбор предметов.

## Готово, когда

- В Unity открыто окно прогулки с персонажем у лестницы.
- Контроллер поднимается по всем пяти маршам, три предмета доступны для подбора.
- Владелец прошёл маршрут и оценил расстановку.

## Подсказки ИИ

Открывать через Tools → Asset Workshop → Walk Tree House. В редакторской прогулке подбор по E убирает пробный предмет и увеличивает счётчик. Кнопка «К началу» возвращает персонажа и восстанавливает предметы.

## Источники

- Assets/Editor/AssetWorkshop/TreeHouseWalkWindow.cs
- Assets/Prefabs/Workshop/TreeHousePrototypes/TreeHouse_Original_Refined.prefab
- tools/assets/CheckTreeHouse185.cs

## Проверка и следующий шаг

В самом окне через Unity MCP проверен подъём по всем пяти маршам контроллером с параметрами Player.prefab и вызван обработчик подбора для монеты, кубка и фонаря. Окно оставлено открытым у лестницы с тремя восстановленными предметами. Инвентарь основного забега не проверялся.

Владелец проходит маршрут и оценивает расположение предметов. ИИ вносит согласованные правки после прогулки.
