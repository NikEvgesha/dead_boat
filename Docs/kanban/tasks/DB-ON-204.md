## Контекст

Владелец попросил перевести шесть крупных береговых композиций из декора в набор игровых остановок LevelEvent. Остановки используют штатные правила спавна, добычи и врагов.

## Готово, когда

- Шесть точек входят в NY_Locations и выведены из случайного фонового декора.
- В каждой точке появляются две доступные находки. Для зимней охраны действует общий шанс уровня. Проходы в тоннеле, бревне и гроте свободны.
- Фоновый декор и замки не перекрывают площадку.
- Старые сохранённые офлайн-копии совместных забегов сохраняют прежний набор остановок.
- Владелец проверил точки в обычном забеге.

## Подсказки ИИ

Префабы точек интереса используют существующие модели как вложенные префабы. Крупные береговые композиции с добычей отделены от семи фоновых вариантов.

## Реализация

Снежный тоннель, полое бревно, ледяной грот, сани с подарками, арка из ёлок и поляна кристаллов подключены к `LocationSpawner`. На каждом берегу по три типа точек. У каждой точки два места для добычи и одно место для охраны, у поляны кристаллов два места для охраны. Для новых точек действует буфер в 60 м от замков.

Оригинальные 16 записей сохранены в том же порядке для старых офлайн-копий совместного забега. Протокол совместной игры обновлён для нового набора локаций.

## Проверка

- Unity загрузила LevelEvent штатным загрузчиком. Генератор создал все шесть типов. В каждой проверенной точке было по две находки, места для добычи и охраны находятся на берегу вне твёрдой геометрии.
- Капсула игрока прошла через тоннель, бревно и грот в обе стороны. Проверка подтвердила удаление пересекающегося фонового декора и пропуск точки, назначенной рядом со вторым замком.
- 700 последовательных выборов генератора для старой офлайн-копии совпали с исходным набором. Совместный забег отдельно не запускался.
- Отчёт Unity в `Docs/locations/previews/event-winter204-play.txt`.

## Следующий шаг

Владелец проекта проверяет в обычном забеге, как точки читаются с лодки и удобно ли высаживаться за добычей.
