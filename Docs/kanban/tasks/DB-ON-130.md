## Контекст
Владелец поручил расширять набор без сборки. Следующая ограниченная пара из CARD_PROGRESSION_PROPOSAL: стрелковый компромисс и защитная альтернатива. Числа прототипа, ручной баланс впереди.

## Готово, когда
- Последний довод I/II/III: +45/60/75% прямого урона последнего патрона, любая перезарядка +15% времени. Один выстрел дробовика усиливает все дробинки, патроны не создаются; передача оружия не переносит личную карту.
- Тяжёлый бушлат I/II/III: +15/20/25% maxHP, −8% скорости один раз. Не выдаёт лечение. С договором множители maxHP 1.15/1.20/1.25 × 0.8, без накопительного повторного применения.
- Идемпотентные личные ранги в solo/Shared recovery/продолжении одному; старые JSON дают0, enum не перенумерованы, несовместимые протоколы разделены.
- Выдача, capIII, обычная альтернатива, отказ рекламного повышения, понятные RU/EN польза/цена/preview проверены.
- Математика, локальный бой/реальные оружейные маршруты и два Photon peer проверены. Владелец принимает баланс/UI позднее, статус in_review до этого. SDK/FEEL не менять, сборки/черновика нет.
