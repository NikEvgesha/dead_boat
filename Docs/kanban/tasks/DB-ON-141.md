## Контекст

У игрока отдельное хранилище животных. Из него можно поставить своё животное в загон личного острова, затем забрать обратно. На пастбище животное случайно гуляет внутри границ. Яйца вылупляются рядом по существующей механике, результат попадает в личный набор животных. Это заменяет прежнее полное скрытие животных в новом общем лобби (DB-ON-041).

## Готово, когда

- Есть отдельный UI животных RU/EN, размещение выбранного экземпляра на своём пастбище и возврат в хранилище с понятным подтверждением результата.
- Экземпляр имеет стабильный ID и одно состояние inventory/pasture: повторное нажатие, reconnect или рестарт не создают дубль и не теряют животное.
- Животные гуляют в пределах своего загона, не блокируют проходы и чужие острова; WebGL-показ ограничен по стоимости и корректно восстанавливается у новых участников.
- Существующие яйца, таймеры/условия вылупления, награды и животные переносятся без сброса; вылупление у личной зоны и получение животного работают также offline.
- Существующий выбор животных/их бонусов в забег сохраняет поведение: простое размещение на пастбище не начисляет новые боевые бонусы само по себе.
- Проверены чужой участок, переполненное размещение, смена комнаты, перезапуск и отсутствие сети. Вместимость задаётся данными; расширения/доход/слияние не добавляются без отдельной задачи.

## Подсказки ИИ

Проверить EggFeatureStorage, Docs/EGG_SYSTEM_SPEC.md, DB-ON-033/034/035/041 и старое личное меню. Повторно использовать вылупление, не писать вторую систему яиц. Сначала определить миграцию данных и отличить владение экземпляром от активного бонуса. Зависимость DB-ON-140.
