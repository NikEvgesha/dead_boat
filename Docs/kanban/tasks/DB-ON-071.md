## Контекст

Владелец удалил часть декора в открытой CastleServicesWorkshop. Сначала сохранить эти изменения. Надписи внутри домов должны перекрываться стенами; оставшиеся деревья заменить на менее полигональные.

## Готово, когда

- Текущие пользовательские изменения сохранены без восстановления удалённых объектов.
- У надписей есть проверка глубины; снаружи за сплошной стеной их не видно, изнутри они читаются.
- Оставшиеся деревья заменены; подтверждено снижение числа треугольников, сохранены размещение и проходы.
- Сцена и актуальный общий префаб сохранены; визуальная приёмка остаётся владельцу.

## Подсказки ИИ

Использовать отдельный материал с проверкой глубины для TextMesh, не менять общий материал шрифта. Сравнивать фактическое число треугольников деревьев. Удалённые владельцем элементы не воссоздавать. Игровые связанные префабы не распаковывать при недоступной основной сборке.
