## Контекст

Каталог HeldItems сопоставляет активный сетевой ID с облегчённой моделью в руке аватара.

## Готово, когда

- Прототип поддерживает стартовый `saber` и покупаемые используемые предметы.
- Положение рук меняется по типу предмета.

## Подсказки ИИ

При новом используемом предмете обновить каталог; детальная проверка на двух клиентах остаётся отдельной задачей.
