## Контекст

Владелец просит украсить стартовый замок и повторяющиеся замки: нарядные ёлки, снег, снеговики. Наполнение и магазины пока сохранить.

## Готово, когда

- NY_Castle имеет цельное новогоднее оформление.
- Один prefab применяется на старте и у CitySpawner.
- Сохранены игровые компоненты, магазины, точки взаимодействия и исходные коллайдеры.
- Есть снимки в Unity для ручной оценки владельцем.

## Подсказки ИИ

Работать только с ивентовым prefab. Старое пробное оформление отключить, сохранять для истории. Декор без боевых скриптов и коллайдеров. Проверять локальные координаты: исходный корень prefab имеет смещение.

## Результат

Ивентовый NY_Castle оформлен как зимний городок: 8 украшенных ёлок, 8 снеговиков, подарки, 68 снежных пятен/сугробов, снег по 7601 треугольнику поверхности крыш, гирлянды на 16 стойках и над воротами. Новое оформление WinterTown_169; старое NewYear_Decoration отключено и сохранено. Геометрия сгруппирована по категориям/материалам: 14 MeshRenderer плюс один для стоек. Материалы/меши в Assets/Events/NewYear/WinterTown169/.

Проверки: сериализованные MonoBehaviour и Collider замка до/после основного оформления совпали (fingerprint); новые элементы без коллайдеров и игровых скриптов. Сохранённый LevelEvent проверен по GUID: стартовый экземпляр и CitySpawner используют NY_Castle. Python из поставки Blender успешно выполнил tools/kanban/server.py --check: OK, 169 tasks.

Общий, уличный вид и снеговик сняты в Unity через отдельную PreviewScene с копией только MeshFilter/MeshRenderer; изображения winter-town169-overview.png, winter-town169-street.png, winter-town169-snowman.png в Docs/locations/previews/ просмотрены. Во время работы другая сессия перевела Unity в Play Mode с TreeHouseVariantsWorkshop; текущую сессию не останавливали и её сцены не пересохраняли. Снимки — предпросмотр префаба, не подтверждение живого игрового забега. Загрузка/проходимость/покупки и появление повторного замка в полном забеге не проверены. Производительность увеличенного декора WebGL ещё не измерена.

Наполнение, ассортимент, исходный общий Castle.prefab и обычные уровни не менялись. Воспроизводимые исходники: tools/assets/WinterTown169.cs и PreviewWinterTown169.cs; дополнительные неровные края наземного снега внесены в сгенерированный Snow_Snow.asset.

Следующий шаг: владелец — оценить изображения и осмотреть обновлённый LevelEvent после завершения текущей игровой сессии; ИИ — внести замечания по плотности снега/ёлкам, затем проверить запуск и повторное появление замка.
