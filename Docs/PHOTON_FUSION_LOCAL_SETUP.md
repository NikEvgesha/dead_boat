# Photon Fusion в репозитории

Версия проекта: Unity 6000.3.9f1, Fusion **2.1.3 Stable Build 2390**.

С 06.11.2026 установленный SDK хранится в Git целиком в `Assets/Photon/`, вместе с `.meta`, нативными/WebGL библиотеками, `NetworkProjectConfig.fusion` и `PhotonAppSettings.asset`. Ручная загрузка или повторный импорт `.unitypackage` после клонирования не нужны. GUID сохраняются: не удаляйте папку SDK перед открытием проекта.

## Запуск другого checkout

1. Выполнить `git pull` в существующем checkout либо клонировать актуальную ветку `codex/online-photon-fusion`.
2. Открыть проект в указанной версии Unity и дождаться автоматического восстановления UPM-зависимостей и импорта ассетов.
3. Проверить отсутствие ошибок компиляции. Для Photon используются уже сохранённые настройки приложения Fusion 2 и конфигурация сетевых префабов. Установленный SDK сам по себе не подключает игру к сети: режим Shared выбирается игровым кодом.

Если SDK ранее импортировали вручную и Git сообщает о конфликтующих untracked файлах, сначала сохраните свою копию/локальные изменения за пределами проекта и сравните их с версией репозитория. Не удаляйте чужие изменения автоматически и не заменяйте GUID произвольным повторным импортом.

`AppIdFusion` — клиентский идентификатор приложения, входящий и в сборку игры; это не сервисный токен и не пароль от Dashboard. Сервисные ключи, токены авторизации и Mirra Cloud API-токены в Git не добавлять. Настройки Mirra Cloud этим изменением не публикуются.

## Почему раньше требовался ручной импорт

Раньше `.gitignore` исключал всю папку `Assets/Photon/` вместе с её `.meta`. Предполагалось держать SDK и App ID локально из-за публичного репозитория. Это делало checkout неполным и требовало повторной установки SDK у каждого разработчика. По запросу владельца исключение убрано; прежние ручной импорт и лимит20CCU не являются актуальной инструкцией запуска или подтверждением текущего тарифа.

Проверка этого изменения: состав SDK и SHA256 файлов в Git (с учётом нормализации переводов строк) сравниваются с установленной рабочей копией. Это проверка полноты поставки, а не заявленный запуск Unity на чужом компьютере. Сборка WebGL не выполняется.
