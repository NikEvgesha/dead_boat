# Проверка Photon Fusion в черновике Яндекс Игр

## Что настроить в Консоли Яндекс Игр

Черновик открывается на реальном адресе Яндекс Игр и применяет Content Security Policy (CSP). На вкладке **CSP** черновика нужно запросить разрешение внешних хостов Photon:

- `*.photonengine.io`
- `*.exitgames.com`

Photon Cloud использует оба домена, а конкретные поддомены зависят от сервера. Установленный Photon Realtime SDK содержит адрес Name Server `ns.photonengine.io`. Если Консоль не принимает wildcard или ревью Яндекса просит точный список, начать с `ns.photonengine.io`, затем добавить адреса Master/Game Server из вкладки Network браузера при реальном запуске. До первой проверки нет оснований считать приведённый список окончательно одобренным Яндексом.

В качестве причины указать: «Photon Fusion Shared: защищённые WebSocket-соединения к Photon Cloud для многопользовательского лобби и кооперативного забега. Конкретные игровые серверы Photon выбираются динамически».

Указывать только имя хоста: без `https://`, `wss://`, пути, порта или IP. Яндекс разрешает `https` и `wss` по умолчанию и рассматривает заявку. Unity WebGL использует WSS для Photon независимо от транспортного выбора в настройках редактора. Отдельный сервер Яндекс Игр или Unity Relay для этого не нужен.

## Первая проверка

1. Дождаться одобрения хостов в CSP и загрузить актуальный WebGL-архив в черновик.
2. Открыть черновик в двух браузерах/на двух устройствах с одинаковой версией сборки и Photon App ID. Проверить, что оба клиента соединяются с Photon и попадают в одну тестовую комнату.
3. При ошибке открыть DevTools → Console и Network → WS. Сообщение `Refused to connect ... connect-src` означает блокировку CSP. Фактический адрес `wss://...` покажет, какой хост нужно добавить. Тайм-аут или ошибка WebSocket без CSP требует отдельной диагностики подключения и Photon.
4. Проверить переход в одиночную игру при отсутствии сети или недоступности Photon. Для релизной версии предусмотреть понятное сообщение и кнопку повторного подключения: это требование Яндекса для внешних хостов.
5. Проверить потерю фокуса и показ рекламы: сетевой сеанс продолжается, а локальные звук и управление должны реагировать на события платформы. В проекте Unity уже включён `Run In Background`.

Доступ к Photon не должен требовать от игрока входа в сторонний аккаунт. Если позднее добавим авторизацию для друзей, на Яндекс Играх допустима авторизация только через Яндекс ID по осознанному действию игрока, с возможностью гостевой игры.
