# Проверка Photon Fusion в черновике Яндекс Игр

## Что настроить в Консоли Яндекс Игр

Черновик открывается на реальном адресе Яндекс Игр и применяет Content Security Policy (CSP). На вкладке **CSP** черновика 424778 отправлен запрос на два домена:

- `photonengine.io`
- `exitgames.com`

Photon Cloud использует оба домена, а конкретные поддомены зависят от сервера. Установленный Photon Realtime SDK содержит адрес Name Server `ns.photonengine.io`. **Консоль отклоняет ввод `*.photonengine.io` как неверный формат.** При этом проверка действующего CSP в игровом iframe показала, что для домена из списка Консоль сама включает `*.домен` в итоговый `connect-src`. Поэтому в поле вводятся базовые домены без `*.`. На 2026-09-25 оба домена отображаются в списке разрешённых хостов черновика.

Локальный WebGL smoke test с правильным Fusion 2 App ID успешно подключил два браузерных клиента к одной Shared Session: оба показали `2/10`. Затем release-сборка была загружена в черновик Яндекс Игр; два клиента в iframe площадки тоже показали `Connected` и `2/10` в той же комнате. Это подтверждает работу SDK, App ID и WebGL/WSS с действующим CSP черновика. Тест проверяет только сетевое подключение, а не синхронизацию персонажей и игрового мира.

В отправленной причине описано назначение каждого домена: `photonengine.io` — первичное подключение к `ns.photonengine.io` и выбор региона; `exitgames.com` — региональные Master/Game серверы Photon Cloud. Оба используются для защищённых WebSocket-соединений многопользовательского режима.

Указывать только имя хоста: без `https://`, `wss://`, пути, порта или IP. Яндекс разрешает `https` и `wss` по умолчанию и рассматривает заявку. Unity WebGL использует WSS для Photon независимо от транспортного выбора в настройках редактора. Отдельный сервер Яндекс Игр или Unity Relay для этого не нужен.

## Первая проверка

1. Загрузить WebGL-архив в черновик после проверки ограничений на размер. Первая **development**-сборка была отклонена Консолью: один распакованный `.wasm` имел размер 149 МБ. Согласно документации Яндекса, суммарное содержимое архива до сжатия должно укладываться в 100 МБ, а `index.html` должен лежать в корне. Проверять весь распакованный размер, а не только размер ZIP. Повторная **release**-сборка заняла 19,4 МБ до упаковки и была принята Консолью как архив размером 18,55 МБ.
2. Для первичной проверки использовать отдельную сцену `Assets/Online/SmokeTest/PhotonConnectionSmokeTest.unity`. Она подключается к комнате `river-yandex-csp-424778` с лимитом 10 и показывает статус/число игроков. В сборку включать только эту сцену; обычные сцены игры и настройки Build Settings не менять. Архив находится в игнорируемой Git папке `Builds/PhotonSmokeTestWebGLRelease.zip`. В тесте остались сообщения Addressables о недостающем `StreamingAssets/aa/settings.json`; на подключение Photon они не повлияли. При интеграции в основную игру эти сообщения нужно устранить и отдельно проверить загрузку контента.
3. Черновик открыт в двух вкладках Яндекс Игр 2026-09-25. Оба клиента показали `Connected` и `2/10`; локальные вкладки были закрыты перед окончательной проверкой счётчика. Черновик: `https://yandex.ru/games/app/424778?draft=true&lang=ru`.
4. При ошибке открыть DevTools → Console и Network → WS. Сообщение `Refused to connect ... connect-src` означает блокировку CSP. Фактический адрес `wss://...` покажет, какой хост нужно добавить. Тайм-аут или ошибка WebSocket без CSP требует отдельной диагностики подключения и Photon.
5. При интеграции с основной игрой проверить переход в одиночный режим при отсутствии сети или недоступности Photon. Для релизной версии предусмотреть понятное сообщение и кнопку повторного подключения: это требование Яндекса для внешних хостов.
6. Проверить потерю фокуса и показ рекламы: сетевой сеанс продолжается, а локальные звук и управление должны реагировать на события платформы. В проекте Unity уже включён `Run In Background`.

Доступ к Photon не должен требовать от игрока входа в сторонний аккаунт. Если позднее добавим авторизацию для друзей, на Яндекс Играх допустима авторизация только через Яндекс ID по осознанному действию игрока, с возможностью гостевой игры.
