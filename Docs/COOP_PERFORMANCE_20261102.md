## Сохранившиеся результаты после сбоя рабочего окружения

Источник: локальный `Logs/OnlineFallbackEditor.log` (не включать целиком в Git: журнал может содержать данные соединений). Два завершённых стресс-прогона содержат PASS создания 100 физических предметов, 20 настоящих ragdoll-трупов, принудительного маршрута 5000 единиц и очистки WorldRear до 4000. Текущая правка кэширует логические позиции экипажа один раз на аудит физики предметов (10 Гц), вместо повторного чтения сетевого состава для каждого предмета. В тестовом harness добавлена проверка изолированного сохранения, временная локальная защита от урона и аварийная остановка при росте allocated memory на 1400 MiB. Это ограничения теста, не новый бюджет игры. Провайдер владельца теперь восстанавливается после выхода из Play, а не в живом уровне. Монитор дополнен monoUsedMB/monoHeapMB.

## Контроль памяти без записи кадров Profiler

После последнего FAIL исследован источник роста, без изменения игрового рантайма. `Profiler.enabled` в Edit Mode был false, но `ProfilerDriver.enabled=true`, `profileEditor=false`: запись автоматически включалась во время Play. В редакторе оставались 2000 кадров (1982–3981). Поэтому runtime-флаг в Edit Mode не отражал настройку записи следующего игрового теста.

`SharedPerformanceTestSave` теперь временно выключает запись Profiler при Prepare и возвращает её исходное значение в EnteredEditMode. Уже собранные кадры не очищаются и не удаляются. ProfilerRecorder игровых маркеров продолжает давать значения. Это исправление измерительного стенда, не оптимизация расхода памяти продукта.

Новый Editor-only `SharedMemoryAudit.Begin/End/Capture` записывает в локальный Logs снимки loaded Unity objects по типам, крупные ресурсы, graphics/Mono/GC, диапазон кадров Profiler и сырые allocator snapshots всех текущих Runner. Скан включает загруженные Editor/asset-объекты, а не только сцену; суммы категорий не являются полным разложением process memory. В сырых SDK полях `objectsFree` обнаруживаются отрицательные значения: их нельзя использовать как доступный бюджет или точный итог всей памяти Fusion. Код SDK не исправлялся. Полный скан каждые 10 секунд сам вносит заметную паузу; FPS/hitches этого диагностического прогона не приёмочные.
