## Кодовое расписание

Рекомендация для 262: единый C# реестр с типизированными датами UTC и полуоткрытым окном[start,end). Без дат — публичный запуск закрыт; отдельный Editor preview не должен обходить допуск в опубликованной игре. Даты меняются разработчиком в коде; это требует обычного обновления сборки, а само наступление заданного окна происходит автоматически. Mirra RemoteConfig/CloudCode для этого не предлагаются.

Тему, content revision, seed, LevelID и версии генератора/пулов фиксировать при принятии забега. Каталог сохраняет ID3 и после закрытия окна: скрывать новый вход, не удалять ресурс, нужный сохранению. Предлагаемое игровое правило — уже начатому экипажу/одиночному забегу дать закончить и разрешить возврат по прежним правилам живого экипажа; новые старты после end закрыть. Правило следует подтвердить владельцу при приёмке перед публичным включением; подготовка проверяемого UI-результата этого подтверждения не ждёт. Проверить countdown через end, старый invite, refresh, смену ведущего и ContinueSolo. NY_Locations7 не содержит полного исторического snapshot старого тестового 23: нельзя выбирать текущую тему по календарю при восстановлении старого забега.
