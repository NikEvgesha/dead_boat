# Каталог деталей, домов и пропсов

Создан по запросу владельца 2026-10-06. [Полный список предметов и данные для Unity](inventory.csv), [все папки и статистика](FOLDERS.md), [машиночитаемая копия](inventory.json).

## Как пользоваться в Unity

Меню **Tools → Dead Boat → Каталог ассетов и мастерская**. Окно ищет по имени, пути, категории и идеям использования. «Найти в Project» выделяет исходный ассет. «Добавить в мастерскую» создаёт экземпляр с Undo в области сборки. По умолчанию показаны префабы и FBX окружения: отключите фильтры, чтобы увидеть остальные форматы, персонажей и UI.

Сцена: `Assets/Scenes/AssetWorkshop.unity`. `01_Assembly_Area` — место сборки возле начала координат; `02_Reference_Gallery` — образцы строительных деталей справа (x ≥ 20). Образцы сохраняют масштаб источника. Галерея — отправная точка, не полный список. В каталоге можно найти остальные предметы и добавить их в сборку. Ctrl+S сохраняет сцену; исходные модели и префабы не изменяются. Не нажимайте Apply на исходные префабы, если меняете только экспериментальную сборку.

## Конкретные детали и идеи повторного использования

Следующие идеи — предложения по названию файла. Форму, pivot, коллайдеры, материалы и пригодность стыков нужно оценить в Unity. Путь в первой группе сокращён: **T = `Assets/Import/kenney_fantasy-town-kit/Models/FBX format/`**.

| Предмет | Где найти | Варианты использования |
|---|---|---|
| Деревянная стойка | `T/pillarWood.fbx` | Угол каркаса дома, опора навеса, стойка перил, ножка стола после изменения масштаба |
| Каменная опора | `T/pillarStone.fbx` | Колонна, фундаментная опора, столб ограды |
| Дощатый настил | `T/planks.fbx` | Пол, мостки, площадка, панель забора; после поворота — стена |
| Половина настила | `T/planksHalf.fbx` | Узкая площадка, ступень, полка, столешница |
| Настил с отверстием | `T/planksOpening.fbx` | Проём под лестницу или люк; проверить форму отверстия |
| Деревянная стена | `T/wallWood.fbx` | Фасад, перегородка, бок сарая |
| Стена с дверью | `T/wallWoodDoor.fbx` | Вход в дом или мастерскую |
| Стена с окном | `T/wallWoodWindowShutters.fbx` | Фасад жилого дома, окно лавки |
| Крыша | `T/roof.fbx`, `T/roofGable.fbx` | Кровля дома, навес, отдельный фронтон |
| Дымоход | `T/chimney.fbx` | Дом с печью, кузница; отдельный элемент может стать каменной тумбой |
| Деревянная лестница | `T/stairsWood.fbx` | Крыльцо, подъём на настил или второй этаж |
| Забор и калитка | `T/fence.fbx`, `T/fenceGate.fbx` | Двор, загон; забор можно использовать как перила |
| Телега | `T/cart.fbx` | Рынок, двор, пристань; возможность выделить колёса зависит от структуры модели |
| Фонарь | `T/lantern.fbx` | Вход, дорожка, таверна; геометрия фонаря не гарантирует источник света |
| Палка | `Assets/Import/Hypercasual Action Props Pack Volume 3/Prefabs/Standard Shader Prefabs/Stick_standardShader.prefab` | Подпорка, часть ограды, ножка мебели; проверить силуэт и масштаб |
| Бочка | `Assets/Models/Item/barrel_small.prefab` | Склад, опора столешницы, порт, кухонные запасы |
| Табурет и стол | В `Assets/Models`, поиск `stool`, `table_long` | Дом, таверна, мастерская; исходные пути перечислены в CSV |

## Что проверено и что остаётся

Первый собранный пример: [деревянный дом](examples/WoodenCottage_01.md), префаб `Assets/Prefabs/Workshop/WoodenCottage_01.prefab`. Находится в `01_Assembly_Area/WoodenCottage_01`. Проверенные размеры и состав приведены в примере.

Второй пример: [каменный дом](examples/StoneCottage_01.md), префаб `Assets/Prefabs/Workshop/StoneCottage_01.prefab`, размещён рядом в x=11. У обоих домов теперь есть объёмная черепица, закрытая кровля, прозрачные окна и проверенный проход.

[Коллекция шести домов](examples/HOUSE_VARIANTS.md): два исходных и четыре новых варианта с разными пропорциями и отдельной обстановкой. Все сохранены отдельными префабами в `Assets/Prefabs/Workshop` и расставлены рядом в мастерской.

[Замок игровых сервисов](examples/CASTLE_SERVICES.md): отдельная сцена CastleServicesWorkshop, стены и башни игрового замка, шесть домов с разным назначением, обстановкой и якорями подключения. Игровые меню и транзакции предстоит подключить.

Каталог основан на обходе всех папок `Assets`. Каждая строка CSV/JSON соответствует существующему файлу. В статистике учтены и вспомогательные файлы: материалы, текстуры, сцены, скрипты и другие форматы. Файлы `.meta` в количество предметов не входят.

Файлы одного предмета в FBX/OBJ/GLTF/STL, варианты материалов и уже собранные префабы не объединялись автоматически: это могло бы потерять различия. Поэтому число строк не является числом уникальных предметов. Категории и идеи сформированы по именам; «Прочее — осмотреть» означает, что назначение пока неизвестно. Наличие FBX ещё не доказывает корректные материалы, импорт, масштаб или коллайдер.

Следующий шаг: **владелец** проверяет мастерскую и выбирает первый дом/пропс; **ИИ** вместе с владельцем собирает его и дополняет каталог проверенными размерами, материалами и способами стыковки.

Проверка в Unity 2026-10-06: сцена открыта и сохранена, 16 моделей в галерее, 5457 записей в окне; поиск, добавление модели с сохранением prefab-связи и отмена одним Undo прошли. Текущий игровой код имеет ошибки отсутствующих типов Photon Fusion. Окно сейчас открыто через MCP; до исправления общей компиляции новый пункт меню может не появиться. Это не мешает текущему просмотру и сборке в Edit Mode. Игровой запуск не проверялся в рамках этой задачи.

Обновление после добавления ассетов: `python tools/assets/build_catalog.py`, затем «Обновить список» в Unity. Генератор перезаписывает только `inventory.csv`, `inventory.json`, `FOLDERS.md`; этот документ остаётся ручным справочником.
