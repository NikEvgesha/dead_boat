# Предложение отключения рекламы — прототип DB-ON-057

После действительно открытого и закрытого ролика появляется боковой значок AD×. Он не открывает окно автоматически. Отказ до SDK onOpen не считается показом; завершение rewarded без награды после onOpen считается показом, но награда за него не выдаётся. Окно имеет русский/английский текст и использует общий UI игры.

Сейчас `Assets/Resources/Monetization/AdRemovalSettings.asset` содержит пустой productId и `lifetimeAutomaticOnlyApproved=false`. Покупка выключена, окно сообщает о будущем предложении. Никакой товар на площадке не создан. Предложенный ID для будущего товара — `remove_ads_auto`.

Перед активацией **владелец** должен подтвердить условия. Подготовленный вариант — постоянное отключение автоматических interstitial, rewarded-видео остаются добровольными и продолжают давать награды только после успешного просмотра. Если нужны срок/подписка/другие правила, сначала изменить модель прав и тексты; не включать флаг постоянного товара для временного продукта.

После подтверждения и создания соответствующего товара **ИИ** задаёт реальный ID и флаг в настройках. Кнопка покупки требует доступного PurchasesManager и данных каталога с ценой/валютой. Цена не зашита в UI; игровой MirraSDKPurchaseProvider теперь сохраняет дробную часть PriceFloat. Положительный callback покупки сохраняет профильное право через SDK.Data. Restore проверяет AllPurchases, а не только PendingProducts, чтобы уже выданный товар тоже возвращал право. Повторная обработка не начисляет дополнительную награду. При праве пропускается запрос interstitial, callback возвращает false («реклама не показана»), поэтому значок не появляется из-за пропуска. Rewarded не подменяется.

SDK/платформа не изменялись: изменены только собственные AdsProvider/AdsManager и игровые MirraSDK-адаптеры. Для других будущих рекламных провайдеров сигнал NotifyOpened нужно вызывать из подтверждённого callback открытия, а не из вызова Show.

Editor проверки с отдельными RAM-настройками и фальшивыми провайдерами: отказ/открытие/placeholder без Buy/цена99.50RUB/успешная покупка/скрытие/interstitial-skip/rewarded PASS. Restore нужного товара/игнорирование чужого/повтор PASS. Реальная покупка и платёжные запросы не выполнялись. SharedAdProtocolProbe с двумя настоящими Photon peers PASS: lease, освобождение руля, действия другого игрока, takeover, grace/timeout/stale callbacks. После тестов Play=false, Runner0, start scene восстановлена, исходные productId пустой/approved=false.

Далее **владелец** — позже принять вид/условия и создать товар; **ИИ** — настроить ID после этого и проверить каталог/restore в общей WebGL-приёмке. Сборка в текущем этапе не выполнялась.
