# Profession System Spec (dead_boat)

Updated: 2026-03-05  
Status: implementation in progress.

## 1) Цель механики

Добавить в лобби NPC, через которого игрок выбирает профессию перед стартом игры.

Профессия влияет на старт:
- дает стартовые предметы,
- может давать валютные бонусы (монеты/гемы),
- может содержать текстовые перки/особенности.

## 2) Игровые правила

1. Базовая профессия (`Юнга`) должна быть открыта всегда.
2. Все остальные профессии стартуют закрытыми.
3. Если выбранная профессия закрыта, кнопка применения заменяется lock-state.
4. Есть кнопка "случайная профессия за хард":
   - списывает гемы,
   - выбирает случайную профессию из закрытых,
   - добавляет ее в открытые.
5. Открытые профессии можно выбрать как текущие.

## 3) Данные

`ProfessionCatalog` (`ScriptableObject`) хранит список `ProfessionDefinition`:
- `professionId`,
- `title`,
- `description`,
- `icon`,
- `defaultUnlocked`,
- `starterItems[]` (префаб + количество),
- `startCoinsBonus`,
- `startGemsBonus`,
- `perkLines[]`.

## 4) Сохранение

Состояние хранится в `ProfessionState_v1`:
- `selectedProfessionId`,
- `unlockedProfessionIds[]`.

Хранилище:
- primary: `MirraSDK.Data`,
- fallback: `PlayerPrefs`.

Нормализация:
- удаление пустых/дубликатных id,
- гарантированное открытие дефолтной профессии,
- авто-ремонт `selectedProfessionId`, если он невалиден.

## 5) Runtime интеграция

- `ProfessionSelectionPanel`:
  - листание профессий,
  - отображение описания/бонусов,
  - применение профессии,
  - рандомное открытие закрытой профессии за гемы.
- `ProfessionNpcPoint`:
  - открывает панель профессий по `E` в trigger-зоне.
- `StarterPackManager`:
  - добавляет стартовые предметы выбранной профессии в стартовый набор.
- `GameManager`:
  - при старте нового рана применяет валютные стартовые бонусы выбранной профессии.

## 6) Ограничения и допущения

- Вероятность рандомного открытия сейчас равномерная по списку закрытых профессий.
- На текущем этапе у профессий нет отдельной сложной логики перков в коде (перки описательные, через `perkLines`).
- Тексты UI пока не локализованы в ключи, это отдельный шаг.

## 7) Критерии приемки

- Игрок открывает панель профессий через NPC в лобби.
- Закрытые профессии нельзя применить.
- Кнопка случайного открытия тратит гемы и открывает случайную закрытую профессию.
- Выбранная профессия сохраняется между сессиями.
- При старте нового рана игрок получает стартовые предметы/бонусы выбранной профессии.
