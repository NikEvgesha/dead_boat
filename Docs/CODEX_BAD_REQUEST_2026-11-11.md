# Ошибка отправки сообщения Codex

Проверка 11 ноября 2026 года.

В локальном журнале Codex подтверждены ответы HTTP 400 на POST к обработчику сообщений `chatgpt.com/backend-api/codex/responses`. Тело ответа содержит только `{"detail":"Bad Request"}`. Сервер не указал поле запроса или конкретную причину отказа.

Последние найденные записи этого чата от 10 ноября по московскому времени:

- 20:57:50, request ID `59443cec-1bd2-4348-9e59-80f9bfc99606`.
- 20:54:52, request ID `ae3cf3f2-183c-4781-b1ce-ad8b4c4087ca`.
- 20:53:54, request ID `693d8654-6650-4fa4-b0f4-00c75762be76`.

Источник — локальная база журналов Codex, прочитанная без изменения данных. Указанные идентификаторы подходят для обращения в поддержку. Токены и содержимое запросов в этот отчёт не включены.

Исправление причины ошибки не подтверждено. Текущая отправка сообщения и выполнение инструментов работают, однако это не доказывает устранение повторяющегося сбоя. Для определения причины на стороне обработчика нужна диагностика команды OpenAI по request ID.

Официальное описание ошибок рекомендует устанавливать причину по конкретным деталям ответа. В найденных ответах таких деталей нет. [OpenAI error codes](https://developers.openai.com/api/docs/guides/error-codes)

Следующий шаг — владелец передаёт request ID в поддержку Codex, если ошибка повторяется. Команда OpenAI определяет причину отказа запроса.
