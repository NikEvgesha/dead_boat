# Обратная связь подбора яйца — DB-ON-033

## Изменение

После успешного локального начисления яйца появляется уведомление: иконка из каталога, «Яйца: +N», «Яиц в запасе: M». Быстрые подборы объединяются в одну панель; общий запас берётся из результата той же операции сохранения, дополнительного чтения SDK ради UI нет.

При первом обнаружении яиц показывается короткое объяснение: яйца хранятся отдельно от сумки, вылупление доступно после возвращения в лобби. Используется существующий `hasDiscoveredEggs`; нормализация старых сохранений и существующее объединение состояния уже сохраняют этот признак. Новых ключей/полей формата состояния нет. Повторный подбор даёт короткое уведомление без повторного обучения. Первая панель — 7 секунд, обычная — 3,5; обновление на unscaled clock, плавное появление/исчезновение. Во время рекламы таймер уведомления приостанавливается.

Canvas не имеет GraphicRaycaster, CanvasGroup не перехватывает ввод, изображения и текст не являются raycast target. Никаких кнопок/паузы/изменения курсора. Одноразовый дубликат и неуспешная операция не показывают награду. Уведомление само не меняет мета-прогресс; ошибка UI не отменяет уже выполненную запись.

`EggFeatureStorage` возвращает `EggPickupReceipt` из той же операции Load/Add/Save. Старые сигнатуры AddEgg/TryAddOneShotEgg сохранены. Обычный и одноразовый Register в EggHatchingManager передают результат в UI; существующее событие EggsCollected сохраняется. В коопе этот код вызывается локальным победителем запроса подбора; новую сетевую рассылку личного мета-прогресса не добавляли. Реальная проверка двух независимых игроков ещё ожидается.

Текст не направляет к видимому в общем пространстве загону/конкретной точке. Личное меню онлайн-лобби остаётся зависимой DB-ON-041 и будет добавлено отдельно; пока не объявляем его готовым. SDK не менялись.

## Доказанные проверки

EggPickupFeedbackProbe PASS, Editor / пустая изолированная сцена, журнал 65965:

- Временный EggFeatureState: 1 → 3 → 4 яйца, one-shot replay не добавляет яйцо; пустой ID/нулевое количество не дают receipt.
- Existing JSON roundtrip сохраняет признак первого обнаружения.
- Панель появляется при timeScale=0; не меняет паузу и не блокирует raycast.
- Быстрые подборы объединяются и сохраняют первоначальную подсказку; по окончании следующее уведомление без неё.
- Во время подставного рекламного состояния панель скрыта, время показа сохраняется.
- UI не меняет переданный временный state; сам тест не читает и не записывает EggFeatureStorage/SDK/запас владельца.

Game View 1920×1080 визуально просмотрен: русский текст и иконка помещаются, нет обрезания. Локальный снимок `Builds/EggPickup-GameView.png`; только для просмотра время панели удерживалось тестом, игровой срок не менялся.

Это проверка результата начисления и UI, не автоматический полный проход реального подбора в одиночном/совместном забеге, не приёмка мобильного экрана и не тест реальной рекламы. Поэтому DB-ON-033 — in_review.
