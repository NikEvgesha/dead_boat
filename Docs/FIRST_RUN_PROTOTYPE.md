## Что показать действием

Основной цикл: поднять/положить/сумка → ценность/продажа/денежная сумка → покупка → топливо/лодка → меч → огнестрел/патроны/перезарядка → животное → карточки/синергия → босс → лобби/яйцо. На пару точек можно свести несколько связанных действий. Профессии и долгий мета-прогресс показывать коротким финальным приглашением в лобби, их полный каталог в десятиминутный ран не помещать. Точный набор остаётся дизайном до сборки маршрута.

Карточки:2обязательных предложения и опциональное3е, каждый раз выбор из небольшого заранее составленного набора. Использовать существующие карточки/RU/EN/FEEL. Первый эффект должен ощущаться сразу; второй показать другое направление или дополнить выбор. Не выдавать случайно неработающий для доступного оружия эффект. Полный каталог карточек не обязателен для первого знакомства.

Животные: временный учебный спутник — рекомендация, ещё не утверждённая постоянная награда. Не включать настоящее многоминутное вылупление посреди рана: нынешнее правило использования яйца в лобби сохраняется. Постоянный подарок/награду за яйцо согласовать отдельно при балансировке; сейчас ничего не начислено.

## Цель и выбор

Дать первую понятную победу и объяснить основной цикл: добыча → сумка → топливо → лодка → угроза → прибытие. Принятые ранее правила: новичок играет офлайн, сценарий повторяемый, закрытие вкладки допускает продолжение, явный выход в лобби закрывает обучение для профиля.
