# Рекламная защита кооператива — 2026-10-14

## Что изменилось

- SharedDepartureState хранит отдельную lease каждого участника: token, состояние показа и сетевой срок. Провайдер запускается только после подтверждения authority (ожидание не более 5 секунд).
- Реклама: до 180 секунд, после закрытия — одна секунда сетевой и локальной защиты. Повторные begin/end не продлевают lease; старый callback не закрывает следующий показ. Состояние переживает смену master.
- Во время показа освобождается руль, authority отклоняет атаки, ручной подбор/перемещение/расход предметов и управление. Автоматическая физическая загрузка свободного топлива ведущим продолжает работать.
- Authority не выдаёт урон защищённому участнику, AI не выбирает его целью. Остальные играют, общая симуляция не останавливается.
- AdsManager завершает запрос один раз при callback, исключении, отключении компонента или realtime watchdog; восстанавливает курсор и отдельную рекламную паузу, не снимая паузу меню.
- Mirra SDK не менялся. Собственный MirraSDKAdsProvider теперь возвращает false для неготового interstitial; презентацией управляет AdsManager.

## Доказанные проверки

Unity 6000.3.9f1, Editor, Fusion Shared Cloud eu; тестовые сохранения и идентификаторы изолированы.

1. SharedAdProtocolProbe, два реальных сетевых runner: PASS. Подтверждённая lease, освобождение руля, запрет подбора смотрящему и разрешение второму, передача authority, неизменность deadline при дублях, grace, истечение без callback и изоляция старых token.
2. Тестовый AdsProvider: PASS. Успех ровно один раз, исключение, отсутствие готовности, зависший callback (ускоренный watchdog) и поздний callback старого запроса.
3. SharedAdGameplayProbe, настоящий LevelForest, игровой клиент и транспортный peer: PASS. Личная смерть, ACK до провайдера, rewarded-воскрешение один раз, работа мира, interstitial, блокировка адресного урона во время показа и grace, возврат урона после grace.
4. Отдельная проверка в настоящем уровне: PASS. Открытое меню остаётся на паузе после двойного рекламного callback.
5. Изоляция: после остановки Play Mode проверяется восстановление ключей return/identity/solo/online mode и стартовой сцены.
