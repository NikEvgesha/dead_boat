# Облики профессий

DB-ON-135 расширяет принятый прототип DB-ON-045 на весь каталог. Все варианты используют один Kenney mesh/rig и существующий аниматор. Меняются только атлас и общий материал; нарисованные броня, маска, монокль и повязки не добавляют геометрию, коллайдеры или игровые бонусы.

ID0/неизвестный ID возвращают исходный материал. IDs1/2 сохранены, остальные добавлены явно, не вычисляются из порядка каталога. Сетевое поле `ProfessionSkin` и протокол skins1 не менялись. Старые клиенты с ограниченным набором ресурсов используют свой fallback для новых ID; для приёмки набора нужны обновлённые клиенты.

Атласы: `Assets/Online/Avatars/Skins/`. Материалы: `Assets/Resources/OnlineUI/AvatarSkins/`. Генерация новых вариантов и исправления UV выполнены imagegen на основе Kenney texture-a; исходный Kenney ассет, механик и охотник в этом расширении не перерисовывались. На части новых голов уточнены отдельные UV-панели макушки/затылка, чтобы фронтальное изображение не оставляло там случайный цвет.

Импорт1024×1024, Repeat (у FBX отрицательные UV), mipmaps, sRGB и сжатие; Read/Write выключен. Материал загружается по нужному ID и кешируется общим для аватаров. Никакой передачи изображений по Photon, дополнительных источников света, частиц или отдельного материала на каждого игрока. Кеш может удержать все встреченные варианты до завершения процесса; это не потоковая выгрузка текстур. Расход памяти и размер архива WebGL требуют измерения после разрешённой сборки.

## Воспроизводимая проверка без Player Build

`ProfessionSkinCollectionTools.ValidateAndCapture()` проверяет покрытие настоящего каталога, уникальность/стабильность ID, все материалы, фактические размеры импортированных текстур, Repeat/mips/nonreadable и наличие прежнего контроллера анимации. Рисует реальный mesh спереди/сзади и отдельные строки с RU/EN подписями. Это статическая галерея, не ручной плейтест движения.

`ProfessionSkinProbe.Run()` расширен для позднего входа с максимальным ID13 и смены всех13материалов, прежнего оружия/аниматора и fallback. В этом этапе отдельный batch-прогон не дошёл до комнаты Photon: OperationTimeout/deadline. Поэтому новая проверка передачи всех13ID **не принята**, прежние успешные проверки двух исходных обликов не выдаются за неё. Неудачный вспомогательный автоматический Play/batch wrapper удалён; остаётся прямой тест для изолированной пустой сцены в рабочем редакторе. Сеть и схема поля не менялись.

Превью: `Docs/previews/AllProfessionSkins.png`, `AllProfessionSkinsBack.png`, `ProfessionSkinsRow1.png`…`Row3.png`. Журналы проверок — локальная папка Logs, не телеметрия игроков. Первые два запуска вспомогательного рендера остановились на ограничениях сцен Unity; итоговый рендер использует проверенную изолированную preview-сцену без её активации. Сборка игры и загрузка черновика в этом этапе не выполняются.

Следующий шаг: **владелец** оценивает лица/одежду по галерее, позднее — в общей веб-проверке; **ИИ** исправляет выбранные варианты по замечаниям. До приёмки DB-ON-135 остаётся in_review.

Итоговая локальная проверка07.11: Validate/галерея PASS, batch exit0, прежний playModeStartScene=null восстановлен. Editor snapshot всех13загруженных текстур ≈17.35MiB, не WebGL heap; финальный сетевой результат — OperationTimeout до комнаты, ожидает повторной проверки.
