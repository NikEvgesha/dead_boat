# Прототип сетевых аватаров в лобби

Сцена `Assets/Scenes/Lobby.unity` содержит объект `Lobby Online`. При переходе в лобби Photon Fusion Shared подбирает свободную комнату или создаёт новую. Лимит задаётся полем `Lobby Capacity` на объекте сцены (по умолчанию 10). `SerialMatching` распределяет игроков между уже существующими комнатами; комнаты с другим лимитом отфильтровываются. Все публичные комнаты этого прототипа находятся в отдельном Photon lobby `river-public-lobby-v1`, поэтому тестовая комната старой версии не участвует в подборе. Каждый клиент создаёт сетевой аватар Kenney; собственная модель скрыта, так как игрок продолжает управлять существующим персонажем от первого лица. Положение и поворот передаются через `NetworkTransform`, а скорость движения включает анимацию ходьбы у других игроков.

При ошибке подключения или обрыве игра остаётся доступной в одиночном режиме. Пока здесь нет приглашений, чата, друзей и совместного забега. Глобальный предел игроков во всех комнатах требует отдельного сервиса учёта; текущий лимит действует на каждую комнату. Автоматический подбор выполняется в пределах Photon-региона игрока.

Подбор использует [официальное описание Photon Fusion Matchmaking](https://doc.photonengine.com/fusion/v2/manual/connection-and-matchmaking/matchmaking): Shared без `SessionName` ищет комнату или создаёт новую, `SerialMatching` распределяет игроков между доступными комнатами.

## Сборка

1. Установить Photon Fusion 2.1.3 в Unity. Папка `Assets/Photon/` исключена из Git.
2. В `Assets/Photon/Fusion/Resources/PhotonAppSettings.asset` указать **Fusion App ID**. Этот файл также не хранится в Git.
3. Выполнить в Unity `Tools > Fusion > Rebuild Prefab Table`, чтобы `LobbyNetworkAvatar` попал в таблицу сетевых префабов. После повторной установки SDK это обязательный шаг.
4. Собрать обычный WebGL-плеер со сценами из Build Settings. Для быстрой проверки только лобби можно временно собрать `Assets/Scenes/Lobby.unity` как единственную сцену; сам список Build Settings менять не требуется.

Модель `character-a` взята из Kenney Blocky Characters; условия использования находятся в `Avatars/Kenney/License.txt`.
