# Прототип сетевых аватаров в лобби

Сцена `Assets/Scenes/Lobby.unity` содержит объект `Lobby Online`. При переходе в лобби он подключается к комнате Photon Fusion Shared `river-lobby-prototype-v1` (до 10 участников). Каждый клиент создаёт сетевой аватар Kenney; собственная модель скрыта, так как игрок продолжает управлять существующим персонажем от первого лица. Положение и поворот передаются через `NetworkTransform`, а скорость движения включает анимацию ходьбы у других игроков.

При ошибке подключения или обрыве игра остаётся доступной в одиночном режиме. Пока здесь нет автоматического распределения по нескольким комнатам, приглашений, чата, друзей и совместного забега. Фиксированное имя комнаты нужно только для проверки двух клиентов.

## Сборка

1. Установить Photon Fusion 2.1.3 в Unity. Папка `Assets/Photon/` исключена из Git.
2. В `Assets/Photon/Fusion/Resources/PhotonAppSettings.asset` указать **Fusion App ID**. Этот файл также не хранится в Git.
3. Выполнить в Unity `Tools > Fusion > Rebuild Prefab Table`, чтобы `LobbyNetworkAvatar` попал в таблицу сетевых префабов. После повторной установки SDK это обязательный шаг.
4. Собрать обычный WebGL-плеер со сценами из Build Settings. Для быстрой проверки только лобби можно временно собрать `Assets/Scenes/Lobby.unity` как единственную сцену; сам список Build Settings менять не требуется.

Модель `character-a` взята из Kenney Blocky Characters; условия использования находятся в `Avatars/Kenney/License.txt`.
