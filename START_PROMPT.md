# Start Prompt / Контекст на старт сессии

Этот файл - короткая стартовая сводка.  
Источник истины всегда в рабочих файлах ниже.

## 1) Обязательные файлы перед началом работы

1. `Assets/Scripts/TODO.md`  
Главный backlog по новой механике (статусы, проценты, приоритеты P0/P1/P2, ручной чеклист Unity).

2. `GPT_JOURNAL.md`  
Журнал контекста по сессиям (что изменено, почему важно, что осталось).

3. `Docs/EGG_SYSTEM_SPEC.md`  
Техническая спецификация текущей egg-механики.

4. `Docs/EGG_SYSTEM_SETUP.md`  
Пошаговая настройка в Unity и smoke-чеклист.

5. `Docs/DOC_WORKFLOW_TEMPLATE.md`  
Шаблон, который можно переносить в другие проекты.

## 2) Базовые правила работы

- Все заметные изменения проходят через `Assets/Scripts/TODO.md`.
- После заметного шага обновлять `GPT_JOURNAL.md` (дата, что изменено, почему важно, что осталось).
- При изменениях в сцене/префабах держать в актуальном состоянии `Docs/EGG_SYSTEM_SETUP.md`.
- При изменениях формата состояния/сохранений обновлять `Docs/EGG_SYSTEM_SPEC.md` и блок проверки миграции в TODO.

## 3) Рабочий ритуал на новую сессию

1. Прочитать файлы из раздела "Обязательные файлы".
2. Уточнить приоритет в `Assets/Scripts/TODO.md`.
3. Выполнить задачу и пройти ручной smoke по затронутому сценарию.
4. Обновить статус в TODO.
5. Добавить запись в `GPT_JOURNAL.md`.

## 4) Быстрый старт для следующего раза

Можно писать так:  
"Используй контекст из `START_PROMPT.md` и работай по TODO/Journal/Docs."
