# Рабочие правила для ИИ-агентов

## Задачи

Локальная доска описана в [`Docs/kanban/README.md`](Docs/kanban/README.md); карточки лежат в `Docs/kanban/tasks/` и передаются через Git. Для онлайн-режима это источник актуального статуса задач. Запуск: `python tools/kanban/server.py`; проверка: `python tools/kanban/server.py --check`.

Перед началом задачи прочитайте её карточку (контекст, критерии, подсказки и источники), затем актуальный код. Отмечайте сделанное по доказанным проверкам. Ручной приёмочный тест, покупка тарифа или публикация не выполняются автоматически. Если результат ещё должен проверить владелец, используйте `in_review`, а не `done`.

При параллельных правках карточек следуйте разделу «Merge карточек и конфликты» в `Docs/kanban/README.md`: сохраняйте сведения обеих сторон и не выбирайте автоматически целый `ours`/`theirs`. Не переиспользуйте ID. Не перезаписывайте несвязанные незакоммиченные изменения в Unity-проекте.

Существующие документы в `Docs/`, `START_PROMPT.md` и `GPT_JOURNAL.md` сохраняют свой контекст. Спецификации описывают намерение; перед реализацией проверяйте, что уже работает в коде и в текущей сборке.
